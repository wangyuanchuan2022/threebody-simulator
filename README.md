# 三体 · 地表观测站

一个可直接双击打开的网页三体模拟器：随机生成三颗恒星与一颗地球，牛顿引力实时演算；主画面是站在地表仰望的天空（大气散射、云层、海面、远山），右上角小图显示四天体的三维位置关系；地球毁灭时注明原因并自动开启下一纪元。

## 运行

**双击 `index.html` 即可**——单文件、完全离线（Three.js r180 与全部源码已内联，约 2 MB）。推荐桌面版 Chrome / Edge（需 WebGL2）。

页内操作：

- 主画面拖动环顾天空，滚轮调整视野（空格暂停，方向键转头）
- 右上角轨道图：拖动旋转、滚轮缩放；点击面板标题可折叠面板
- 时间流速五档（0.01 – 30 天/秒）
- 「新世界」随机重启；「重放此世界」按种子复现
- 「纪元记录」查看历代世界的死因与生存天数
- 「观测设置」：渲染精度（着色器 LOD 与像素比上限）、曝光、云量、自动重启

URL 支持 `index.html?seed=42` 固定种子。

### 天空的读法（原著语义）

三颗恒星在真三维空间中随机分布、由牛顿引力自由演化。恒星**远离时角尺寸极小，只呈现为一点亮星——飞星**；当它接近地球时角尺寸按物理规律迅速增大，**骤然胀成一轮巨日**，天空随之被散射光淹没。天空中的恒星方向与右上角轨道图始终一致。

两类天体用不同的亮度模型，这也是观感差异的来源：

- **飞星**：点像，亮度取**视流量** L/d²——太远就自然变暗，永远不刺眼。
- **太阳**（圆面宽于约 2–3 像素后）：亮度取**表面亮度**（与距离无关），近距离掠过时白热过曝并照亮整片天空。

天空与云层用**同一个时钟**，因此它们的时间速率**始终跟随所选倍速**：

- **物理时钟**：按所选倍速推进，轨道图与遥测数字反映真实模拟状态。
- **天空/天气时钟**：默认就等于物理时钟——切换到 5 或 30 天/秒时，太阳划过天空的速度、云层漂移的速率都会同步加快，切回低倍速也立刻变慢。云层用模拟日计时（1 模拟日 = 20 个着色器时钟单位），海洋波纹仍用墙钟，避免高倍速下波纹频闪。
- 若不喜欢高倍速下必然出现的昼夜快速明暗（时间混叠），可在「观测设置」勾选**高倍速时平滑天空**：天空被限速到 1.5 天/秒，代价是天空相位会滞后于遥测显示的模拟日，直到倍速回落到上限以下再瞬间对齐。

### 卡顿与画质

「渲染精度」档位直接控制大气着色器的步进 LOD 与像素比上限：均衡（8 步/3 阴影步，像素比 1）、高画质（10/3，1.25）、超清（12/4，1.5）。默认「均衡」为流畅优先，独立显卡可上调。

## 真实地形（可选）

默认画面里的远山是着色器程序化山脊（无模型时的回退）。要换成真实地形，两条路线都支持：

**A. Terrain2STL（推荐，真实 SRTM 高程，零素材成本）**

1. 打开 jthatch.com/Terrain2STL，框选任意山区（或直接填坐标/地名），导出 zip。
2. 解压出的 `.stl` 放到 `assets/terrain.stl`，执行 `node build.mjs`。
3. Terrain2STL 是 **Z-up 实体**、无材质贴图：本项目会自动做 Z-up→Y-up 旋转、按**高程与坡度生成顶点色**（低地/岩壁/雪线/近水湿暗），并按包围盒等比缩放。

**B. 建模站 GLB（有贴图、观感更"照片级"）**

1. 在 Sketchfab 等站下载 **.glb**：**贴图内嵌**、**非 Draco / 非 KTX2 压缩**（未内联对应解码器）、建议 CC0/CC-BY 且 ≤ 30 MB。
2. 放到 `assets/terrain.glb`，执行 `node build.mjs`。

两者都可显式指定路径、构建时以 base64 内联进单文件（页面仍可双击直开、完全离线）：

```
node build.mjs --terrain D:\downloads\terrain.stl --out index.html
```

**自动安置**：模型按包围盒等比缩放（默认跨度见 `src/app.mjs` 顶部 `TERRAIN.span`），水平居中于观测点，并向下投射射线找到观测点正下方的地表，把它对齐到海平面——于是观察者站在地面上（相机 18 m 高）、山峰从海面升起、低于海面的部分自然没入水中。已嵌入模型时着色器的程序化山脊自动关闭，改由真实网格 + 三盏恒星平行光照明。

验证链路：`node tests/make-terrain-fixture.mjs` 生成最小 GLB 测试件；`node build.mjs --terrain tests/fixtures/terrain.glb --out terrain-test.html` 与 `node build.mjs --terrain assets/terrain.stl --out stl-test.html` 构建两条路线的变体，浏览器测试断言网格真实挂载、三角数 >1000，且 STL 路线带顶点色（`observatory.test.terrainInfo()`）。

## 毁灭判定（沿用原著术语）

| 界面用词 | 判据（简化模型） | 原著对应 |
|---|---|---|
| 大撕裂 | 进入恒星洛希极限（刚体近似） | 原著第二十章标题「大撕裂」 |
| 坠入太阳 | 与恒星表面相交 | 乱纪元中太阳逼近吞噬行星 |
| 乱纪元 · 三日凌空 | 均温 >120°C 连续 8 天 | 原著第十六章「三日凌空」 |
| 乱纪元 · 长夜 | 均温 <−100°C 连续 30 天（地表生态终结，行星仍在） | 乱纪元的长夜与严寒 |
| 被抛出三体世界 | 距质心 >30 AU 且比轨道能量为正 | 行星被混沌引力抛出星系 |
| 恒星相撞 · 观测终止 | 超出点质量模型范围，重启但**不计为**行星毁灭 | 模型适用边界，非原著情节 |

界面上的纪元标签沿用原著二分：**恒纪元**（温度宜居且天空有太阳）与**乱纪元**（其余情形），极端时标为「文明警报」；太阳远离时提示为**飞星**，三颗齐现时即**三日凌空**。

温度采用单区热惯量近似（辐射平衡目标 + 14 天弛豫），天空为三光源单次散射近似。这些是可视化模拟，不是天文或气候预测。

## 工程结构

```
index.html          构建产物（单文件交付物，勿手改）
build.mjs           构建脚本：node build.mjs [--terrain x.glb] [--out y.html]（确定性输出）
src/                源码：physics.mjs / shaders.mjs / app.mjs / index.html 模板
vendor/             Three.js r180 固定版 + GLTFLoader/BufferGeometryUtils（构建输入，MIT）
style.css           样式（随 HTML 外链，需与 index.html 同目录）
assets/             可选：放入 terrain.glb 后重新构建即嵌入
tests/              物理断言（node）+ 浏览器集成测试（playwright）+ 覆盖率 + GLB 测试件生成器
security-reports/   three@0.180.0 依赖安全审查报告存档
```

物理引擎：四体牛顿引力 + 自适应步长 Velocity Verlet（近遇自动细分），单位 AU / 太阳质量 / 天。三颗恒星初值在球壳内**均匀随机采样**（含最小间距拒绝采样），速度取随机三维切向——初始构型不是共面环。地表观察者固定北纬 25°、23.44° 轴倾角，自转与轨道共用同一模拟时钟（天空有其自身的显示时钟，见上）。渲染分两趟：全屏天空/海面着色器 + 真实透视相机的地形场景（三盏恒星平行光 + 雾）。

## 测试

```
node tests/physics.mjs      # 50+ 断言：能量守恒、判据分支、种子复现（行覆盖 100%）
python tests/browser.py     # 无头浏览器：渲染、交互、毁灭重启链路、离线性（行覆盖 100%）
node tests/coverage.mjs     # 覆盖率汇总（physics / app 双 100%）
```

修改 `src/` 后执行 `node build.mjs` 再刷新页面。浏览器覆盖率按「构建产物行号 ↔ 源码行号」1:1 映射统计（`build.mjs` 刻意保持行结构不变）。

## 依赖安全

Three.js 0.180.0（MIT）整包静态扫描判 BLOCK（示例解码器含长编码数据、个别示例库 eval、WebGPU 动态节点），经用户批准仅采用其固定版本 WebGL 核心，内联进单文件；页面运行时零外部请求。报告见 `security-reports/`。
